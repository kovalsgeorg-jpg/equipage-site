# EQUIPAGE кейтеринг — сайт для equipaj.ru

Одностраничный сайт в визуальном мире «Вечерняя дорога экипажа»: тёмная
кинематографическая сцена как продолжение видео, температурные тона
(графит, умбра, олива, вино), латунь как свет фонарей, крем включается в
«рабочих» секциях (меню, форма). Полное описание мира: `DESIGN.md`.
Стек: Next.js 15, TypeScript, Tailwind CSS 4. Бренд: EQUIPAGE латиницей +
знак-карета, Cormorant Garamond + Golos Text.

Две темы: вечерняя (по умолчанию) и дневная светлая «тихая роскошь»;
переключатель в шапке, выбор запоминается (localStorage `eq-theme`),
видео-hero и подвал остаются вечерними в обеих. Правила: `DESIGN.md`.

Секции: видео-hero → «С чем вы к нам пришли?» (три двери по типу заказчика)
→ услуги журнальными разворотами → «Стол, дорога и люди» → бегущая строка
заказчиков → меню с фильтрами (крем) → конфигуратор «Прикиньте бюджет за
минуту» → «Дорога заказа» с прорисовкой маршрута по скроллу → галерея-лента
(scroll-snap, кадры видео шире фото) → стандарты → рейтинг Яндекс Карт →
FAQ → форма (крем). Механики: счётчики цифр, Ken Burns на фото, магнитные
кнопки, липкая мини-CTA. Всё уважает prefers-reduced-motion.

## Запуск

```bash
npm install
npm run dev        # http://localhost:3000
```

Проверки:

```bash
npm run build      # производственная сборка
npm run lint       # линтер
npm test           # тесты (валидация формы, целостность контента и ассетов)
```

## Где редактируется контент

**Один файл: `src/config/site.ts`.** Контакты, услуги, преимущества, позиции
меню и фильтры, шаги заказа, галерея, стандарты, отзывы, FAQ, реквизиты,
имена заказчиков для бегущей строки, пути к видео. Пометки `[ЗАМЕНИТЬ]` —
данные, требующие проверки владельцем.

- **Отзывы:** массив `testimonials` пуст, блок цитат скрыт; показывается
  подтверждённый рейтинг Яндекс Карт. Добавьте реальные цитаты, блок
  включится сам.
- **Меню PDF:** положите файл в `public/` и укажите путь в `menuPdf`.
- **Фото:** `public/images/`. Все текущие фото — собственные съёмки компании,
  включая три стоп-кадра из фирменного видео (video-*.jpg).
- **Видео hero:** `public/video/` (mp4 + webm + постер).
- **Политика ПД:** `src/app/privacy/page.tsx`, согласовать с юристом.

## Интеграции

Скопируйте `env.example` в `.env.local`:

- `LEAD_WEBHOOK_URL` — приёмник заявок. `POST /api/lead` валидирует данные
  (zod) и пересылает JSON на этот адрес (CRM, Telegram-бот, почтовый шлюз).
  Пока не задан, форма честно говорит, что онлайн-приём не подключён,
  и показывает телефон и почту. Ложного «отправлено» нет.
- `NEXT_PUBLIC_METRIKA_ID` — счётчик Яндекс Метрики. Сайт шлёт цели
  `lead_submit` (успешная отправка формы) и `phone_click` (клик по номеру).
  Цели с этими именами нужно создать в интерфейсе Метрики (тип «JavaScript-событие»).

## Seedance 2.0 (по брифу — отложено)

Видео-пролёты «процесса» (кухня, логистика, монтаж) генерируются только после
утверждения сметы в кредитах Higgsfield (ориентир: ~550–700 кредитов на
десктопную связку). Место в структуре: секция «Как проходит заказ». ИИ-генерация
еды запрещена брифом.

## Что ещё нужно от владельца

1. Приёмник заявок (вебхук или адрес почты/CRM).
2. Номер счётчика Метрики для equipaj.ru.
3. Ссылки Telegram и WhatsApp (поля в конфиге пусты, кнопки скрыты).
4. Реальные отзывы с согласием авторов.
5. PDF-меню для кнопки скачивания (если нужна).
6. Проверка фактического адреса производства и текста политики ПД.
7. Решение по Seedance-пролётам (см. выше).

## Деплой

`npm run build && npm start`, любой Node-хостинг или Vercel. Важно:
www.equipaj.ru сейчас указывает на Tilda — для публикации нужно перевести DNS
на новый хостинг. Шрифты Google скачиваются при сборке (next/font) и раздаются
с сайта; машине сборки нужен доступ к fonts.googleapis.com.
